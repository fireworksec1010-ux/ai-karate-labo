# Karate Japan Guide

空手の歴史・流派・大会結果・強豪校・道場・日本への空手留学を、日本語 / English / Español で紹介する静的サイト（非公式）。
ビルド不要。`index.html` をダブルクリックで確認できます。

## ページ
| ファイル | 内容 |
|---|---|
| `index.html` | 目的別入口・歴史年表・流派比較・競技ルール |
| `compete.html` | 大会カレンダー・最新結果 |
| `schools.html` | 強豪の中学・高校・大学（学校／組手・形／地域で絞り込み。`?type=jhs` `?str=kata` などで初期条件指定） |
| `dojo.html` | 流派の本部・統括団体、全中で上位の道場・クラブ、沖縄で学ぶ、道場選びのチェックリスト |
| `study.html` | ビザ・留学の流れ・費用目安・FAQ・用語集 |
| `contact.html` | お問い合わせ（宛先は食品価格サイトと共通。`assets/app.js` の `CONTACT_EMAIL` で変更） |

## データ（ここを編集して更新）
| ファイル | 内容 |
|---|---|
| `data/schools.js` | 強豪校。**直近の全国大会入賞実績があり、出典記事で確認できた学校のみ**掲載。出典URLは `SOURCES` |
| `data/events.js` | 大会カレンダー `CALENDAR` と最新結果 `RESULTS`（大会後に先頭へ追加） |
| `data/dojos.js` | 流派団体 `ORGS`、全中上位の道場・クラブ `CLUBS`、沖縄の窓口 `OKINAWA` |
| `data/content.js` | 歴史・流派・ルール・入学方法・ビザ・費用・FAQ・用語 |
| `data/i18n.js` | 画面文言と情報確認日 `DATA_DATE` |

## 更新の目安
- 3月（全国高校選抜）、8月（インターハイ・全中）、11月（全日本大学）、12月（全日本選手権）の後に結果と強豪校を更新
- 費用・ビザ情報は年1回見直し
- 選手名の英語表記は読みが未確認のため漢字のまま（確認できたらローマ字に）

## 言語（日本語 ja / 英語 en / スペイン語 es）
- データの各項目は `{ ja, en, es }`。`es` が無い項目は英語→日本語の順で代わりに表示されます（学校名・地名など固有名詞は英語表記のまま）。
- 画面文言は `data/i18n.js` の `es` ブロック。言語を増やすときは同じ形のブロックを追加し、`assets/app.js` のボタンを1つ足します。
- 選手名・道場名は読みが未確認のため、どの言語でも漢字表記。
